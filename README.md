# DSB

This repository contains the backend code for the web-based Digital Suggestion Box for UR-CST.

## Overview

This project is a Go-based RESTful API for user management, featuring user registration and login functionalities. It utilizes the Gin framework for routing and Swagger for API documentation.

## Prerequisites

- Go 1.16 or later
- Git

## Getting Started

Follow these steps to clone the repository and start the server.

### 1. Clone the Repository

Open your terminal and run the following command to clone the repository:

```bash
git clone https://github.com/Mr-Ndi/DSB.git
cd DSB
```

### 2. Install Dependencies

Run the following commands to install necessary dependencies:

```bash
go mod tidy
go install github.com/codegangsta/gin@latest
```

### 3. Run the Server

Start the server using either of the following commands:

```bash
gin run main.go
```
or
```bash
go run main.go
```

The server will launch locally, allowing you to interact with the API.
